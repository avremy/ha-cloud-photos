Re-authenticate iCloud

Used when iCloud asks for a fresh login (about every 30 days, or after a password change). Clicking the button below launches iCloud's own authenticator inside this page — enter your Apple ID password (not an app-specific password) and the 6-digit code Apple pushes to your trusted device.

Help — code not arriving on my iPhone?

Apple changed something with iOS 26.4 that breaks the usual 2FA push to iPhones when icloudpd asks for it. Workaround:

  1. On your iPhone, swipe down from the top-right to open Control Center
  2. Turn on Airplane Mode (and turn Wi-Fi off too if it stays on)
  3. Open Settings → [your name] → Sign-In & Security
  4. Tap Get Verification Code — a 6-digit code appears
  5. Enter that code into the iCloud authenticator above and submit
  6. Once authenticated, turn Airplane Mode back off

The "Get Verification Code" option only appears when the iPhone is offline — that's why airplane mode is required. More background on this Apple bug.

When you see "Authentication successful" above (and the session pill goes green), you can close this and run a sync.
